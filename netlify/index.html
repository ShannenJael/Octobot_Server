Netlify Edge Proxy Active

OctoBot Server Gateway

This Netlify domain serves as the secure reverse proxy gateway for your OctoBot application. Requests to octobot-server.netlify.app are forwarded dynamically to your remote 24/7 container.

⚡ Awaiting Backend Configuration
The proxy is ready and waiting for your container origin URL. Once configured in Netlify, visiting this URL will immediately render your live OctoBot application.

How to Connect Your Cloud Container

1

Deploy the Container

Host the container on any 24/7 cloud host (AWS, GCP, DigitalOcean, Render, Railway, or VPS) using the Dockerfile in this repo.

2

Set Netlify Environment Variable

In your Netlify Dashboard → Site configuration → Environment variables, add:

Key:   OCTOBOT_BACKEND_URL
Value: https://your-octobot-host.com (or your server's public IP:PORT)
3

Reload

Reload this page. The Netlify Edge Function will instantly proxy all routes, webhooks, and API calls to your live OctoBot instance.
