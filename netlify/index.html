OctoBot Server

This Netlify page is a public project page for the Tabletmasters OctoBot server repository. The OctoBot trading app itself runs as a Docker container.

Local app URL http://localhost:5002
Container octobot-local
Internal port 5001

Run the project locally from PowerShell:

cd "C:\Users\pascu\Downloads\OctoBot\OctoBot"
docker compose up -d --build --force-recreate
